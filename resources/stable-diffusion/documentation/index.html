Stable Diffusion XL Interactive Sketch & Inpainting Tool

This is a personal project designed to transform rough sketches into photorealistic outputs and facilitate inpainting edits. Leveraging open-source Stable Diffusion XL pipelines, it integrates ControlNet for robust sketch-based guidance and offers an intuitive Tkinter interface for generating, refining, and saving high-quality imagery.

NOTE: Everything can be run locally

Overview

This application leverages the Diffusers library and multiple Stable Diffusion XL pipelines to offer an interactive interface for generating and editing images. By integrating ControlNet, the user’s sketch is respected as a guidance map, ensuring the final output aligns with the original drawing. In inpainting mode, users can paint a mask directly on the generated result to refine or alter specific details in the image.

Example applications: - Quick concept art generation - Generating variations of a manually drawn design - Editing or refining existing AI-generated images

Key technologies: - Python 3.9+ - Torch (CUDA-enabled) - Hugging Face Diffusers - Stable Diffusion XL (with ControlNet + Inpainting models) - Tkinter for GUI - Pillow (PIL) for image manipulation

Features

  1. Sketch to Image
  2. Draw simple sketches or outlines on a white canvas.
  3. Real-time inference triggers to generate preview images using SDXL + ControlNet.

  4. Customizable prompts (subject, style, environment, etc.).

  5. Inpainting Mode

  6. Switch to inpainting mode to refine or modify parts of the generated image.
  7. Paint a mask (in red) onto areas you want to replace.

  8. Click "Apply Inpainting" to let the SDXL inpainting pipeline fill the masked areas.

  9. Undo & Eraser

  10. Undo your last stroke (in regular sketch mode).

  11. Toggle eraser vs. brush for quick corrections.

  12. Prompt-based

  13. Simple text input fields to craft unique prompts.

  14. Negative prompts to avoid undesired content.

  15. Saving Results

  16. Save your generated images in multiple formats (JPEG, PNG, etc.).

Models Used

The code leverages several pretrained models from Hugging Face:

  1. ControlNet Model: xinsir/controlnet-scribble-sdxl-1.0
  2. Stable Diffusion XL Base Model (with ControlNet): SG161222/RealVisXL_V4.0_Lightning
  3. Inpainting Pipeline Model: diffusers/stable-diffusion-xl-1.0-inpainting-0.1

Note: You can substitute these models with similar SDXL-compatible ControlNet or inpainting models if desired.

Usage

  1. Sketch on the left canvas using the default black brush.
  2. Adjust brush size with the slider.
  3. Undo (Ctrl+Z) to revert the last stroke.

  4. Toggle Eraser to switch between drawing and erasing.

  5. Enter prompts in the text fields:

  6. Subject (e.g., a futuristic car)
  7. Design Features (e.g., sleek lines, aerodynamic)

  8. Environment (e.g., cyberpunk city at night)

  9. Click "Inference" to generate a preview image on the right panel.

  10. (Optional) Inpainting:

  11. Once satisfied with a generated image, click "Enter Inpainting Mode."
  12. Paint red mask strokes on the areas you want to modify.
  13. Click "Apply Inpainting" to update those masked regions.

  14. Click "Exit Inpainting Mode" to return to normal sketching mode.

  15. Save your image by clicking "Save Generated."

Technical Details

  1. Stable Diffusion XL Pipeline
  2. Used StableDiffusionXLControlNetPipeline to condition the generation on the user’s sketch.

  3. Employed AutoPipelineForInpainting for targeted refinements in the inpainting workflow.

  4. ControlNet

  5. ControlNet ensures the user’s sketch (converted to an inverted grayscale image) influences the generated result. We set controlnet_conditioning_scale to control how strongly the sketch shapes the output.

  6. Inpainting Approach

  7. A separate model or pipeline is used for inpainting. We produce a mask from the user’s red strokes and pass it alongside the base image to fill in the masked areas.

  8. GUI with Tkinter

  9. Canvas element to draw lines, handle mouse events, and store user strokes.

  10. ImageDraw from the Pillow library keeps an internal representation of the user’s drawing for inference.

  11. Performance Considerations

  12. Generating images with SDXL can be GPU-intensive.
  13. The number of inference steps or the image resolution can be tuned to fit performance constraints.

  4. Provide a semi-transparent overlay instead of painting in pure red for an improved user experience.

  6. Include preset prompts for quick concept generation (e.g., portrait, landscape, cartoonish, etc.).

  8. Optionally keep the user canvas size flexible, adjusting the model’s input resolution accordingly.
