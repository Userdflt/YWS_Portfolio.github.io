01THE OVERVIEW

An idea with
a practical purpose.

Notion MCP Agent turns a Notion workspace into a live, AI-driven knowledge hub with one-click text-to-speech. A FastMCP server exposes a toolbox for manipulating Notion pages; a LangChain agent with GPT-4o orchestrates conversations to read, write, summarise, build tables, manage metadata, and generate MP3s of notes in real time. It runs over SSE transport with a Tkinter desktop GUI, and can run local-first with Ollama LLMs and Coqui TTS at zero cloud cost.

The challenge

Notion is the centre of gravity for personal and team knowledge — but interacting with it through chat usually means dumb question-answering. The agent should be able to *do* things, not just describe them.

01

FastMCP as the tool layer

Every Notion verb (create, append, query, schema) is a typed MCP tool.

02

LangChain + LangGraph orchestration

GPT-4o reasons over the workspace and chains tool calls.

03

TTS output

Spoken summaries of meeting notes, journals, and PRs as MP3.

02HOW IT WORKS

From input
to insight.

  1. 01

    User types

    Question or command entered in the Tkinter GUI.

  2. 02

    Agent plans

    LangChain agent decides which MCP tools to invoke (chain-of-thought shown in dev mode).

  3. 03

    FastMCP executes

    Server hits the Notion API and/or Coqui TTS over SSE.

  4. 04

    Agent streams

    Answer streamed back, plus an MP3 link when TTS is used.

  5. 05

    Result lands

    Change appears instantly in the Notion workspace and desktop chat window.

IN PRACTICECAPABILITIES & ARCHITECTURE

The thinking
behind the system.

End-to-end workspace control from chat

Append blocks, build tables, rename pages, manage users, search.

Text-to-speech

Any content becomes a downloadable MP3 via Coqui TTS.

Structured-Notes mode

Generates ten-section pedagogical study guides.

Real-time interaction

Conversations run over SSE transport on an /sse endpoint.

Local-first desktop app

Works offline with local LLMs.

Extensible tool surface

New MCP tools can be added without touching core logic.

Architecture & technical details +
  • A FastMCP / MCP-Python server registering content, page, user, search, and media tools — append_content, create_table, get_page_text, search_notion, text_to_speech.
  • LangChain + LangGraph orchestration; ChatOpenAI gpt-4o by default, swappable for any Ollama or OpenAI-compatible model.
  • notion_client SDK, Coqui TTS, a Tkinter GUI, asyncio over SSE transport.
  • Code layout: notion_mcp_server.py, notion_agent.py, tts_service.py.
