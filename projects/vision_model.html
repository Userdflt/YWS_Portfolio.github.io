01THE OVERVIEW

An idea with
a practical purpose.

An AI-powered personal project that simplifies information retrieval from NZ Building Code documentation, extracting, indexing, and retrieving both textual and visual data from PDFs with an open-source stack. Images pass through an ImageMetadataExtractor where vision models generate descriptive metadata; text is chunked and embedded; both are stored in Chroma. AI agents retrieve the combined text and image data and generate answers via open-source LLMs behind a Streamlit chat interface.

The challenge

Standard text RAG drops the diagrams. For a code document, the diagram often *is* the answer.

01

Vision-language captioning

LLaMA Vision via Ollama captions every figure on extraction.

02

Multi-modal index

Captions + text chunks share an embedding space in ChromaDB.

03

Graph retrieval

LangGraph composes the retrieve → answer → verify path.

02HOW IT WORKS

From input
to insight.

  1. 01

    PDF identification

    Auto-detects Building Code PDFs by filename prefixes/suffixes.

  2. 02

    Content extraction

    Text and images extracted (Unstructured).

  3. 03

    Dual processing

    Split into two concurrent streams — image stream and text stream.

  4. 04

    Image metadata

    Images stored as paths + base64; ImageMetadataExtractor + vision models generate descriptive metadata → Chroma.

  5. 05

    Text embedding

    Text split into chunks, embedded via SentenceTransformers → Chroma.

  6. 06

    Retrieve

    AI agents fetch relevant text AND image data by query embedding.

  7. 07

    Answer

    Open-source LLM generates the response in the Streamlit chat UI.

IN PRACTICECAPABILITIES & ARCHITECTURE

The thinking
behind the system.

Locally deployable

Secure, privacy-focused, and fully open-source end to end.

Dual processing streams

Vision-model image extraction runs alongside text chunk embedding.

Combined retrieval

Text and visual data are retrieved together for comprehensive results.

Conversational retrieval

Quick, context-sensitive answers over the indexed documentation.

Architecture & technical details +
  • Document extraction with Unstructured.
  • Vision analysis via open-source Vision Transformer models on HuggingFace.
  • SentenceTransformers embeddings held in a Chroma vector store.
  • Open-source LLMs (Ollama models, GPT-Neo, LLaMA) behind a Streamlit UI.
